# Member Next App

Phase 03 회원관리 화면 실습 프로젝트입니다. Next.js App Router, TypeScript, ESLint, npm을 사용하며 Tailwind CSS는 사용하지 않습니다.

## 실행

```powershell
npm run dev
```

브라우저에서 <http://localhost:3000>을 엽니다.

## 코드 검사

```powershell
npx tsc --noEmit
npm run lint
npm run build
```

1강 화면은 정적인 첫 화면이며 API나 데이터베이스에 연결하지 않습니다.
