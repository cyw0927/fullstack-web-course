# Chapter 02 학습 기록

## 오늘 이해한 HTML 구조

HTML은 단순히 화면에 글자를 표시하는 언어가 아니라 문서의 구조와 의미를 표현하는 마크업 언어라는 점을 이해했다.

기본 문서는 `html` 안에 `head`와 `body`가 있고, 사용자가 실제로 보는 콘텐츠는 `body` 안에 작성한다.

HTML 요소는 서로 부모, 자식, 형제 관계를 가진다.

```text
body
├─ header
├─ main
│  ├─ section
│  └─ section
└─ footer
```

이 구조는 브라우저의 DevTools Elements 탭에서도 트리 형태로 확인할 수 있으며 이후 DOM을 학습할 때도 중요한 개념이다.

## 내가 사용한 시멘틱 태그와 선택한 이유

- `header`: 페이지의 대표 제목과 설명을 담기 위해 사용했다.
- `main`: 이 페이지에서 가장 중요한 학습자 정보와 학습 내용을 묶기 위해 사용했다.
- `section`: 회원 정보, 현재까지 배운 내용, 앞으로 배우고 싶은 내용처럼 서로 다른 주제를 구분하기 위해 사용했다.
- `footer`: 현재 학습 단계와 Chapter 정보를 문서 하단에 표시하기 위해 사용했다.

모든 영역을 `div`로 작성하는 것보다 각 영역의 의미가 코드에 직접 드러나기 때문에 문서 구조를 이해하기 쉽다.

## LLM에게 질문한 내용

### 질문 1

HTML에서 `header`, `main`, `section`, `footer`를 사용하는 것이 모든 영역을 `div`로 만드는 것보다 왜 좋은가?

### 확인한 답변

시멘틱 태그는 각 영역이 어떤 역할을 하는지 태그 이름 자체로 설명할 수 있다. 따라서 사람이 코드를 읽기 쉽고 검색엔진이나 보조 기술도 문서 구조를 이해하기 쉬워진다.

### 질문 2

다음 구조에서 부모, 자식, 형제 요소는 무엇인가?

```html
<main>
  <section>
    <h2>회원 정보</h2>
  </section>
  <section>
    <h2>학습 목표</h2>
  </section>
</main>
```

### 확인한 답변

- `main`은 두 `section` 요소의 부모이다.
- 두 `section`은 `main`의 자식이다.
- 두 `section`은 같은 부모를 가지므로 서로 형제이다.
- 각 `h2`는 자신이 포함된 `section`의 자식이다.

## LLM 답변 중 내가 직접 확인한 내용

작성한 `index.html`과 `assignment.html`의 소스 구조를 확인해 다음 내용을 검토했다.

- `h1`은 문서마다 한 번만 사용했다.
- `header`, `main`, `section`, `footer`가 실제 계층 구조에 맞게 배치되어 있다.
- 같은 `main` 아래에 있는 여러 `section`이 형제 관계이다.
- 목록 형태의 정보에는 `ul` 또는 `ol`을 사용했다.
- CSS와 JavaScript는 사용하지 않았다.
